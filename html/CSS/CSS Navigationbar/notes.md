What is Navigation bar?
-A navigation bar (also called a Navbar) is a user interface element that contains group of links that lead to different pages of a web-site.
-Navbars are either vertical or horizontal.

Why Navigation bar?
-The navigation bar is an important element of a website's design since it allows users to quickly visit any section within the website.
-Navigation allows a user to find exactly what they would be looking for in no time.
