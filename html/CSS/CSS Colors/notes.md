CSS Colors:

- CSS uses color values to specify a color
- Colors are specified using predefined color names, RGB, and HEX values

CSS Colors- Hex Codes:
A hexadecimal is a 6 digit representation of a color. The first two digits(RR represnt a red value, the next two are a green value(GG), and the last are the blue value(BB).
Ex:
#000000
#FF0000

CSS Colors- RGB Values:
This color value is specified using the rgb() property. This property takes three values, one each for red, green, and blue. The value can be an integer between 0 and 255 or a percentage.

Ex:
rgb(0,0,0)
rgb(255,0,0)
rgb(0,0,255)
rgb(0,255,0)
