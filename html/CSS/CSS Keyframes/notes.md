CSS Keyframes:
*The CSS Keyframes rule specifies the animation code in the page.
*The animation is created by gradually changing from on set of CSS styles to another.
Syntax:
@keyframes animationname {keyframes-selector {css-styles;}}

Ex:
@keyframes animel{
    from{top:0px;}
    to{top:100px;}
}
The element will gradually move from 0 to 100px downwards
